연구원 개개인의 실제 전문성을 데이터로 정리하고, 서로 비슷한 전문성을 가진 사람과 적합한 과제를 찾아주는 "보유 전문성" 화면을 구축했습니다. 임베딩만으로는 표면적 어휘 일치와 실질적 업무 일치를 구분할 수 없다는 한계를 보완하기 위해, 근거를 직접 확인하는 LLM 정성 판정 단계를 추가해 신뢰도를 높였습니다. 다음 단계로는 실제 연구원을 대상으로 한 소규모 파일럿 검증을 제안합니다.

①지금까지 만든 것

대시보드에 "보유 전문성" 화면을 추가했고, 아래 4개 탭으로 구성됩니다.

연구원

연구원별 보유 전문성 카드

학력·과제 이력·직무 이력·핵심기술·보유기술·논문·특허를 종합해, 연구원 한 명 한 명의 강점 분야/키워드/Hard Skills/Domain Knowledge를 카드로 정리해 보여줍니다.

연구원 ↔ 연구원

전문성이 비슷한 사람 찾기

과제가 완전히 달라도 실제 보유 전문성이 겹치는 연구원을 찾아 보여줍니다. 시니어를 먼저, 그다음 주니어 순으로 표시하며, 근거 없이 점수만 높은 매칭은 제외합니다.

연구원 ↔ 과제

과제·직무와 연구원 매칭

"과제 기준"(이 직무에 맞는 사람은 누구인지), "인별 기준"(이 사람에게 맞는 과제는 무엇인지), "과제 전문성"(과제별 필요 전문성 딥다이브)을 한 화면에서 확인할 수 있습니다.

전문성 MAP

전사 전문성 지도(산점도)

모든 연구원의 전문성을 2차원 지도 위에 점으로 뿌려, 가까이 모인 점일수록 실제로 비슷한 일을 하는 사람들임을 한눈에 보여줍니다.

②어떻게 동작하는가 — 왜 신뢰할 수 있는가

모든 결과는 아래 5단계를 거쳐 만들어지며, 특히 3 → 4단계로 넘어가는 부분이 이 기능의 신뢰도를 결정하는 핵심입니다.

1원본 정리인사·과제·조직도 데이터를 표준 형식으로 정리
→
2전문성 추출(LLM)연구원·과제 이력을 사내 LLM이 분석해 핵심 분야/키워드 도출
→
3임베딩전문성 설명을 벡터화 — 의미가 비슷하면 벡터도 가까워짐 (저비용 1차 후보 추리기)
→
4정성 판정(LLM)후보에 대해서만 LLM이 실제 근거를 대며 한 번 더 확인 — 근거 없으면 제외
→
5화면 표시근거·신뢰도와 함께 리포트로 표시
✓ 신뢰도 확보 포인트
임베딩(3단계)은 "단어가 비슷한지"만 볼 수 있어, 둘 다 "AI"를 언급해도 실제로는 신호처리 vs 자연어처리처럼 완전히 다른 업무일 수 있습니다. 그래서 후보로 추려진 사람에 대해서만 LLM이 실제 근거(개조식 문장)를 직접 제시하며 재확인하고, 근거를 대지 못하는 매칭은 애초에 화면에 나타나지 않도록 걸러냅니다. "유사도 점수가 높다"만으로는 화면에 노출되지 않는다는 뜻입니다.
⚠ 아직 검증되지 않은 부분
위 구조는 설계상의 신뢰도 확보 장치이며, 실제 정확도를 사람이 측정한 적은 아직 없습니다. 다음 단계로 제안하는 파일럿 검증은 바로 이 부분 — "실제로 얼마나 정확한가"를 소규모로나마 확인하기 위한 절차입니다.

③다음 단계: 파일럿 검증 계획

전사 확대에 앞서, 부서 1곳을 대상으로 한 소규모 파일럿 검증을 다음 단계로 제안합니다. 정식 설문 도구 없이 아래 체크리스트만으로 진행할 수 있는 가벼운 방식입니다.

Step 1 · 대상 선정

파일럿 부서 1곳 선정, 소속 연구원 5~10명 + 부서장 1명 참여

Step 2 · 개인별 확인

본인 프로필 정확도(체크리스트 A) + 유사 인물 추천 타당성(체크리스트 B) 확인

Step 3 · 부서장 확인

과제-인력 배치 추천이 실제 배치 감각과 맞는지 확인(체크리스트 C)

Step 4 · 결과 집계

체크리스트 결과를 취합해 정확도(%)로 요약, 개선점 도출

검증 항목 상세

  • (a) 본인 프로필 확인 — "연구원" 탭의 본인 카드를 보여주고, 강점 분야/키워드/Hard Skills/Domain Knowledge가 실제 본인 전문성을 정확히 나타내는지 확인
  • (b) 유사 인물 추천 타당성 확인 — "연구원 ↔ 연구원" 탭에서 나온 추천 목록(근거 포함)을 보여주고, 실제로 비슷한 일을 하는 사람이 맞는지 + 제시된 근거가 타당한지 확인
  • (c) 과제-인력 배치 감각 확인 — 부서장에게 "연구원 ↔ 과제" 탭의 "과제 기준" 추천을 보여주고, 실제 인력 배치 판단과 얼마나 맞는지 정성적으로 확인
